ARM-ALPHA explores how environmental sound recognition can provide additional environmental awareness for people with hearing impairments.

The project combines machine-learning experimentation with an assistive hardware concept that communicates detected sounds through vibration patterns.

**What I worked on**

- Explored an audio-classification workflow using Python and machine-learning techniques.
- Worked with the UrbanSound8K environmental sound dataset.
- Connected software experimentation with a hardware concept involving a Raspberry Pi, microphone, and vibration motors.
- Contributed to model development and refinement, with approximately **95% accuracy reported in project experiments**.

**Engineering perspective**

The challenge is not only to classify sound, but to consider how model output can become useful feedback in an assistive experience.
