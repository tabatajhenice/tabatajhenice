PROJECT 01 / AI + ACCESSIBILITY

ARM-ALPHA

Environmental sound recognition for assistive technology

AI
Python Machine Learning UrbanSound8K Raspberry Pi Embedded Systems

ARM-ALPHA explores how environmental sound recognition can help people with hearing impairments become more aware of their surroundings. The concept connects machine-learning experiments to a wearable assistive device that translates detected sounds into vibration patterns.

System architecture
01 / Audio input A microphone captures environmental sounds.
02 / Processing A Raspberry Pi supports the hardware concept.
03 / Classification A model is trained and evaluated with UrbanSound8K.
04 / Feedback Vibration motors communicate detected sound categories.
  • Developed and refined an environmental audio-classification workflow.
  • Worked with Python and machine-learning experiments using UrbanSound8K.
  • Connected software experiments to a hardware concept involving a microphone, Raspberry Pi and eight vibration motors.
  • Contributed to model refinement, with approximately 95% accuracy reported in project experiments.
The challenge is not just recognizing a sound. It's translating a model's output into feedback that can be useful in someone's everyday life.
